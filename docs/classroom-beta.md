# Omnixa Classroom Beta 使用说明

欢迎加入 Omnixa Classroom Beta！这是一份给普通同学看的快速上手说明。

## 1. 注册与邀请码

1. 打开首页，点击「开始使用」进入注册页。
2. 填写邮箱、用户名、密码（至少 8 位）。
3. 如果有班级邀请码，在「邀请码（可选）」中填写；没有邀请码也可以直接注册。
4. 注册成功后会自动登录，并赠送一批 Beta 体验积分。

> 邀请码由老师/管理员发放。邀请码有使用次数上限，过期或用完会提示无效。

## 2. 积分（Credits）

- 在侧边栏「用量 / Usage」页面可查看**当前余额**与**每条使用记录**。
- 不同模型档位消耗不同积分：自动 / 快速 / 均衡 / 深度思考。
- 图片理解、使用资料（RAG）、Agent 等能力也会按规则消耗积分。
- 余额不足时会提示「积分不足，无法继续生成」，不会产生额外扣费。

## 3. 对话与学习项目

- **项目**：在「项目」页创建学习项目，可以使用模板（如「课程知识库」「面试复习」），说明与指令可随时修改。
- **对话**：在「Chat」页发送消息。可以切换模型档位（自动/快速/均衡/深度思考）。

## 4. 图片理解

- 点击输入框左侧「图片」按钮选择图片（支持 JPG / PNG / WebP，单张不超过 10MB）。
- 发送后 AI 会结合图片回答。历史消息中的图片在刷新后仍然可见。

> Beta 期间图片理解为体验能力，具体模型以实际配置为准。

## 5. 使用资料（Knowledge / RAG）

1. 在「Knowledge」页上传资料（支持 TXT、Markdown、PDF，不超过 10MB）。
2. 等待资料状态变为「可用」（上传后由后台自动处理，一般很快）。
3. 回到 Chat，把能力切换到「使用资料」，即可基于资料提问，回答会标注来源。

> 处理失败的资料可以点击「重新处理」。

## 6. Agent 与 Workflow

- 「Agent」能力可执行多步任务；「任务 / Workflow」页可查看运行状态（排队/处理中/完成/失败）。

## 7. 充值（Beta 人工审核流程）

1. 在「定价 / 充值」页选择套餐或输入自定义金额，点击提交。
2. 申请进入待审核状态，由管理员人工确认收款后到账。
3. 可在该页「我的申请」中查看状态（待审核 / 已通过 / 已拒绝）。

> Beta 期间不支持自动支付；请勿向任何"自动到账"的二维码付款。未配置收款码时页面会提示暂未开放扫码充值。

## 8. 意见反馈

- 侧边栏「意见反馈」随时可以提交问题或建议，管理员会收到并处理。

## 9. 常见问题

| 问题 | 说明 |
| --- | --- |
| 忘记密码 | 联系管理员重置（Beta 暂未开放自助找回）。 |
| 积分不够 | 提交充值申请，或联系管理员。 |
| 图片上传失败 | 检查格式（JPG/PNG/WebP）与大小（≤10MB）。 |
| 资料一直处理中 | 稍等片刻；若超过 5 分钟请联系管理员。 |
| 邀请码用不了 | 可能已过期或用完，找老师要新的。 |

## 10. 隐私提示

- 你的对话、上传的资料与图片仅用于本 Beta 系统内部，管理员可以看到用量与反馈。
- 请不要上传任何敏感或涉密内容。
- 本产品处于 Beta 阶段，不构成任何正式认证或合规承诺。
